DAILYTOOLS GLOBAL - READY TO UPLOAD

Files:
- index.html
- style.css
- script.js
- about.html
- privacy.html
- terms.html
- contact.html

UPLOAD:
1. Extract this ZIP.
2. Upload ALL files into your hosting public_html (or website root).
3. Make sure index.html is directly inside the website root.
4. Open your domain.

FREE OPTION:
GitHub Pages can host this static site for free:
- Create a GitHub repository.
- Upload all files.
- Settings -> Pages -> Deploy from branch -> main.
- Open the generated Pages URL.

IMPORTANT BEFORE ADS/MONETIZATION:
- Replace the Contact page placeholder with a real contact email/form.
- Review Privacy and Terms for your actual services.
- If you add Google Analytics, AdSense, affiliate links, or forms, update the privacy/cookie disclosures accordingly.
- Add a real domain/canonical URL in index.html.
- Submit the site to Google Search Console after launch.

COUNTRY LOCALIZATION:
The country selector changes the currency used by the EMI calculator and saves the choice in the browser. The current starter supports India, USA, UK, UAE, Canada, Australia, Germany and France. Language supports English and Hindi. More country-specific tools/pages can be added later.
